# dsh-fish-message

DSH 的 QQ 私聊通道。它把 QQ 私聊与 DSH 会话连接起来，双向传递文字、图片和语音文件，
并在 DSH 未运行或 QQ 暂时离线时保留消息、等待恢复后补发。

---

## 1. 用途

- 在 QQ 私聊与 DSH 会话之间互传消息，目前仅支持私聊。
- 支持文字、图片、语音文件的收发，以及普通文件的发送。
- 支持按名称或标签发送表情包，并可管理自己的表情包。
- DSH 或 QQ 未运行期间收到的消息，会在恢复后补发；暂时发不出去的消息先保存在本机，
  恢复后按顺序重试，不会直接丢失。
- 语音合成、语音分析和入站图片识图由可选的「本地 AI」插件提供；没装时其它功能照常。
- 收到的图片按内容指纹缓存识别结果；同一张图再来直接用上次的描述，不再重复识图。

---

## 2. 安装

### 2.1 准备

- 已安装并可正常使用的 DSH。
- 本机已安装 QQ 登录服务（如 NapCat），并已登录需要使用的 QQ 号。
- Node.js 20 或更高版本。

### 2.2 安装插件

在本目录执行：

```powershell
pnpm install
dsh plugin --profile desktop add .
```

然后确认 DSH 的插件配置中已启用鱼讯。

### 2.3 避免重复接收

如果之前使用过其他 QQ 桥接插件，请先停用，否则同一条 QQ 消息会被处理两次。

### 2.4 生效

安装或更新插件后，下一次 DSH 启动时加载。启动后打开「设置 → 鱼讯 QQ」。

> 若当前正在 DSH 会话中，让 DSH 重新加载插件会结束该会话，请另开一个终端执行。

## 3. 使用

### 3.1 连接 QQ

在设置页「连接设置」中填写 QQ 登录服务地址；服务启用了鉴权时再填写访问令牌。
连接正常时，页面顶部显示「在线」。

### 3.2 绑定会话

在「私聊绑定」中，为每个 QQ 号选择一间 DSH 会话。关闭「启用」后，该 QQ 号不再收发消息。
每行第一列的称呼仅用于区分不同联系人。

### 3.3 发送消息

DSH 的回复默认只发送 `[QQ]…[/QQ]` 标记内的内容，其余部分留在 DSH。若希望整条回复都发送，
可在「消息处理」中关闭该限制，此时标记本身会被去掉。

```text
[QQ]这段会发送到 QQ。[/QQ]

[QQ]第一段[/QQ]
[QQ]第二段（两段会合并为一条消息）[/QQ]
```

### 3.4 发送图片、语音与文件

```text
[图片:C:\图片\示例.png]
[语音]晚安，主人[/语音]
[语音:C:\音频\示例.wav]
[文件:D:\文档\示例.pdf]
```

本地 AI 插件可用时，`[语音]文字[/语音]` 会把原文交给本地 AI 服务合成语音条；
文字过长时按句子切成多条语音依次发送，不会截断。朗读化（数字、单位、符号等
转成中文读法）由本地 AI 服务统一处理。也可以用 `[语音:路径]` 直接发送本机已有
的音频文件。插件没装或没启动时，语音相关功能会给出提示，
文字、图片、文件和表情照常收发。文件能否发送成功，取决于 QQ 登录服务的版本与权限。

收到图片或表情包时，本地 AI 插件可用则先在本机识别，把描述和图片路径一起递进会话。
提示词可在设置页「本地 AI 服务 → 图片识别提示词」中修改，留空使用默认。
识别结果会按内容指纹存进收图图库（见 3.6），同一张图再来直接用上次的描述，
不再重复识图，也不再塞原图；要看原图时让智能体调 `fish_image_get`。
插件没装或没启动时，图片照常作为附件和路径递入。

### 3.5 表情包

在设置页「表情包」中可设置保存位置、自动保存、数量上限与占用空间上限，并点击「管理表情包」
进入独立的管理页。管理页支持上传、搜索、编辑标签与描述、删除、直接发送，以及一键打开表情库文件夹。

发送表情时，可使用名称或标签：

```text
[表情:打哈欠]
[表情:#睡觉]
```

找不到对应表情时会在 DSH 会话中提示，不会静默跳过。

### 3.6 收图图库

收到的图片会按内容指纹（sha256）在图库里存一份「原图 + 描述」，下次同一张图再来就不必重新认：

- 有描述：直接把上次的描述递进会话，不再识图，也不再往上下文里塞原图；
- 没有描述：按「收到图片后先在本地识图」的设置重新识别，补上描述，并在消息里说明「这张图之前没有描述，已补上」；
- 本地识图关着：把原图递进会话，并提醒智能体看完后用 `fish_image_note` 把描述写回图库；
- 识图失败：退回原图，不写库，下次这张图会重新识别。

没有命中时按设置识图，成功就把原图和描述一起入库。图库是缓存：超过条数或占用上限会自动淘汰
最久没见到的图片，不提示；表情包是收藏，永远不会被自动删除。默认位置在 DSH 家目录下的
`fish-message-images`。

收到的图都会先进收图图库，但只有开了自动保存或被手动存下的图才会进表情库——两者是两套
独立存储（各自的目录和索引）：图库淘汰不会删表情库的原图，表情库删除也不影响图库。

命中缓存时只给描述。需要亲眼看原图时，让智能体用工具取：

| 工具 | 作用 | 代价 |
|---|---|---|
| `fish_image_get` | 按内容指纹（或本机图片路径）取回图库里的原图：能看图时直接返回图片，否则返回本机路径 | 原图占上下文，比读描述贵；要细节才取 |
| `fish_image_note` | 给某张图写或改描述（回执里会说明是否覆盖了旧描述） | 不改图片本身，只改缓存 |

设置页「收图图库」里的选项：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 收图先查图库 | 开 | 关掉后完全退回旧行为：每次按识图设置重新识别，不查库也不写库 |
| 图库条数上限 | 1000 | 超过上限时淘汰最久没见到的图片 |
| 原图占用上限（MB） | 512 | 只算图库自己存的原图 |
| 在图库里存原图 | 开 | 关掉只留描述与尺寸；入站缓存被清理后就没法回看原图 |

图库与本地 AI 插件无关：没装本地 AI 时，已有描述的图照样能用缓存；只是没描述的图认不出来。

### 3.7 离线补发与待发消息

DSH 或 QQ 未运行期间收到的消息，会在恢复后按时间顺序补发；超过「离线消息补发范围」的旧消息
只发送一条汇总提示。暂时发不出去的消息会先保存在本机，可在「待发消息」中查看积压情况、
立即重试或清空。清空后这些消息不再补发。

### 3.8 日志

设置页底部显示最近日志，可滚动查看。日志只保留最近一段时间，重启后重新开始记录。

## 4. 已知缺陷

- 仅支持私聊，群聊暂不支持。
- 文件发送依赖 QQ 登录服务的版本与权限，部分环境可能无法发送。
- 待发消息严格按顺序补发：前一条长期发送失败时，后面的消息会一起等待。
- 极少数情况下补发可能重复一次（消息已送达但记录尚未清除时）。
- 表情包预览使用原图，较大的动图加载会稍慢。
- 表情包达到上限后需要手动清理，不会自动删除旧表情。
- 更换表情包保存位置后，原有图片不会自动迁移。
- 语音合成、语音分析和入站图片识图依赖可选的本地 AI 插件；没装时这些功能不可用
  （收图图库本身不依赖它，但没描述的新图认不出来）。
- 收图图库满了会淘汰最久没见到的图片，淘汰后同一张图再来会重新识图。
